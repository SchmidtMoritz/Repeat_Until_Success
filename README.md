# Repeat Until Success Qiskit Demonstration

This repository contains slides and example code of a talk I held at IBM in 2022. Back then, Qiskit did not support proper conditional behavior to simulate repeat until success circuits that are part of a proposed [quantum neuron model](https://arxiv.org/abs/1711.11240).

Sadly, I do not have a requirements.txt anymore. The Qiskit version was at most v0.34.2 if not older.
